# Freight-Forwarder

A professional freight forwarding website landing page for air and sea cargo logistics.

## Features

- Modern landing page with hero section, services, stats, tracking, and contact form
- Tailwind CSS styling for a polished logistics brand feel
- Mobile-friendly layout and visitor-friendly conversion sections
- Ready for extension into full quote request and shipment tracking features

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production build

```bash
npm run build
npm run start
```
